# Handoff

WP-06 consumes Store/task identity and generation to issue server capabilities. StartIntent must commit before external spawn. ConfirmStarted cannot prove no hidden model call. Unknown/expired runs remain active and need reconciliation; a database transaction cannot make child effects exactly once. Target must match frozen locked target or approved auto candidate, while current admission/quota/permission must be checked at the later execution exit.

Plan revisions are immutable and only unstarted bindings can change during active execution. Snapshot Verify is integrity, not authentication. Route rows can be drafts; do not equate SaveRoute with real admission. EvidenceRef is a reference, not a passed report.
